# InDesign 文字セットの書体へ置換

`Std / StdN / Pro / ProN / Pr5 / Pr5N / Pr6 / Pr6N`など、文字セットだけが異なる同系列の和文フォントへ置換するInDesign用JSXです。

変換元フォントがインストールされていない文書にも対応し、本文・スタイル・合成フォントをまとめて処理できます。

## 対象

- ドキュメント本文（すべてのストーリー）
- 段落スタイル（スタイルグループ内を含む）
- 文字スタイル（スタイルグループ内を含む）
- 合成フォント内の各構成書体

## 使い方

1. `文字セット書体置換.jsx`をInDesignの「Scripts Panel」フォルダーへ入れます。
2. InDesignで対象ドキュメントを開きます。
3. `ウィンドウ ＞ ユーティリティ ＞ スクリプト`から実行します。
4. 一覧で現在のフォントを選択します。
5. その行の変換先をプルダウンから選択します。
6. 必要な行を設定し、`置換`をクリックします。

変換先プルダウンには、次の条件を満たすフォントだけが表示されます。

- 現在Macにインストールされている
- 現在のフォントと同じ書体系列
- 現在のフォントと同じスタイル／ウェイト
- 現在とは異なる文字セット

候補が存在しないフォントは一覧から除外されます。各行の初期値は`（変更しない）`です。

変換元のフォントはインストールされていなくても対象になります。たとえば、文書内で不足している`Pr5`書体に対して、Macにインストール済みの同系列・同ウェイトの`Pr6N`書体を変換先として選択できます。不足フォントは一覧に`（未インストール）`と表示されます。

本文では使われず、合成フォントの構成書体として文字列だけが保存されている不足フォントも検出対象です。

## Max / MaxNについて

`Max`と`MaxN`は文字セット名ではなく、利用可能な候補から収録文字数の多い書体を選ぶために使われるプリセット名です。本スクリプトではフォント名の文字セット表記として扱いません。

## 判定方法と制限

- フォントファミリー名、フルネーム、PostScript名から文字セット表記を検出します。
- CIDフォントでは`registry`と`ordering`も和文フォント判定に利用します。
- 文字セット表記を含まない書体や、同系列と安全に判定できない書体は対象外です。
- 相互入れ替えなど、変換指定が循環する組み合わせは同時に実行できません。
- ロックされたテキストや編集不能な合成フォント項目などは変更できない場合があります。
- スクリプトは検索・置換設定を処理後にクリアします。
- 実行前に保存し、最初は複製ドキュメントで確認してください。

## 対応環境

InDesign ExtendScript（`.jsx`）用です。構文確認は行っていますが、InDesign実機上でのフォント候補表示・本文置換・合成フォント変更は未確認です。
